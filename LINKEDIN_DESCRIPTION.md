## Version Détaillée (Alternative)

🚀 **Dir-Khir** - Plateforme d'Entraide Citoyenne

Réalisation d'une plateforme web complète permettant aux citoyens marocains de coordonner l'entraide de proximité dans leurs quartiers (nettoyage, aide scolaire, dons urgents).

**Contexte :**
Développement d'un prototype fonctionnel pour une association de commerçants et citoyens, présenté à des investisseurs sociaux. Solution à un problème réel : la gestion chaotique de l'entraide via les groupes Facebook.

**Stack Technique :**
• **Frontend :** Next.js 15 (App Router), React Server Components, TypeScript
• **Backend :** Server Actions, API Routes
• **Base de Données :** PostgreSQL (Neon.tech) avec Drizzle ORM
• **Authentification :** Better-Auth (sessions sécurisées)
• **UI/UX :** Tailwind CSS, Shadcn/UI, design responsive
• **Validation :** Zod pour les schémas de données
• **Outils IA :** Cursor IDE, v0.dev pour l'accélération du développement

**Fonctionnalités Implémentées :**
✅ Système d'authentification complet (inscription/connexion/déconnexion)
✅ Publication de besoins avec formulaire multi-étapes
✅ Filtrage dynamique par ville et catégorie
✅ Système de participation avec compteur de volontaires en temps réel
✅ Dashboard utilisateur avec deux vues (mes demandes/mes engagements)
✅ Marquer les besoins comme résolus
✅ Intégration WhatsApp pour la coordination directe
✅ Design traditionnel marocain (motifs zellige, couleurs artisanales)
✅ Interface 100% responsive (mobile, tablette, desktop)
✅ Notifications toast pour le feedback utilisateur

**Compétences Acquises/Améliorées :**
🎯 **Next.js 15 :** Maîtrise de l'App Router, Server Components, Server Actions
🎯 **TypeScript :** Typage strict, interfaces, génériques
🎯 **Better-Auth :** Configuration et gestion de sessions sécurisées
🎯 **Drizzle ORM :** Requêtes SQL typées, relations, migrations
🎯 **Zod :** Validation de schémas côté client et serveur
🎯 **Tailwind CSS :** Design system, responsive design, animations
🎯 **Shadcn/UI :** Composants accessibles et personnalisables
🎯 **Architecture :** Séparation des responsabilités, Server Actions, gestion d'état
🎯 **UI/UX :** Design responsive, accessibilité, expérience utilisateur
🎯 **Outils IA :** Intégration de Cursor et v0.dev dans le workflow de développement

**Résultat :**
Prototype fonctionnel livré en temps record, démontrant une maîtrise complète du développement full-stack moderne avec les dernières technologies.
